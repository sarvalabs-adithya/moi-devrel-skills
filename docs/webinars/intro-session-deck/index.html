02
The basics

MOI in four ideas.

Everything today maps back to one of these.
01 · Participants
State lives with the participant
A person, a company, an agent. Its data sits on its own account, and the ledger links each change to every participant it touched.
02 · Interactions
MOI's transaction
A signed request to change one or more participants. It costs fuel, paid in KMOI, the native token.
03 · Native assets
Tokens are a protocol feature
MAS0 is the fungible standard; KMOI runs on MASN. Create, transfer, lock and release without token code.
04 · Logics
Programs, written in Coco
Deployed on MOI. They read and write participant state. The agent registry is one.

Why agents belong on MOI.

07
Where it runs

Your laptop, your key, our relay.

Your laptop
runtime.cjs under pm2
  • Holds the agent's private key
  • Runs the template on schedule
  • Signs every relay request
The relay
The launchpad server
  • Verifies the agent's signature
  • Holds the bot token and the LLM key
  • Meters 10 AI calls a day
Telegram
@moinetworkbot
  • Delivers only to the owner
  • Recipient from our records, never the request
  • Nothing crosses between users
Every relay call is signed with the agent's own key, the same secp256k1 over blake2b the wallet uses. The server recovers the key and checks the agent is registered and active. No bearer tokens.
08
The marketplace

Publish it. Price it. A logic settles it.

// contracts/agent_market/agent_market.coco — abridged endpoint dynamic List(agent Identifier, price U256): // the creator's wallet signs this prices[agent] = price; creators[agent] = Sender endpoint dynamic Subscribe(agent Identifier, seller Identifier): // the buyer signs this if creators[agent] != seller: throw "seller does not match the on-chain listing" memory token = PayToken(asset_id, Sender) token.Transfer(beneficiary: seller, amount: prices[agent]) // exactly the listed price
Subscribe has no amount parameter. The price comes from on-chain state, so a buyer cannot underpay or redirect it. The server never holds the money. The buyer gets a clone: a new identity they own, on their machine.
