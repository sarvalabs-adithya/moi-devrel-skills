# MOI Marketing UI Kit

Hi-fi recreation of the moi.technology marketing surface, built from the
Figma file's hero compositions (X-Banner, X-Posts, four-step product
panel). **No production codebase was provided** — this is a visual
reconstruction, not a port.

`index.html` is a single-file click-through prototype showing:

- Top navigation with logo + mono nav.
- **Hero** with the Pip mascot orbiting on the right, headline left,
  validator count chip, primary/secondary CTAs.
- **"Your authority, four ways."** four-card feature row — Exist · Monitor · Scope · Revoke.
- **The participant layer** — code snippet on cosmos background.
- **Validators band** — number + animated dot grid.
- **Footer** with mono wordmark + handle.

Components live in `components.jsx`. To open, run `index.html`.
