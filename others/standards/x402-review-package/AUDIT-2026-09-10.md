## Fixed after the first audit pass (same day, Stellar comparison)

- `getExtra()` key was `feesSponsored`; Stellar and its spec use `areFeesSponsored`. Renamed;
  spec's `PaymentRequirements` example and field list updated.
- `assetDecimals` was documented as enabling money strings, which `parsePrice` refused
  regardless; and with no decimals known, core's display path assumed 6 for KMOI (which has 9).
  Fixed by shipping KMOI as a default asset, accepting `"0.10 KMOI"`, adding
  `registerMoneyParser` for dollar prices, and giving the client `findDefaultAsset`.
- Eight server tests added; suite 36/36 on rc2. ESLint and Prettier clean.
