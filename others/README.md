# Others

Material that is not a skill and not a handover doc, kept because the skills and the handover docs were built from it or point to it. Nothing here is needed to run a product day to day; start with the handover docs in `project-handover-docs/` and come here for background.

| Folder | What it holds | Start with |
|---|---|---|
| `research/` | Seven research notes written by Claude (an AI research assistant) in September and October 2026, from Adithya's transcripts, repos, Drive and request history. They are the evidence the skills in `skills/moi/` were designed from. Each note has a "Read first" block, a list of known inconsistencies and a glossary | The note for the area you need: `webinars-early.md` and `webinars-mature.md` (Builders sessions), `community-call.md`, `release-blog-social.md`, `docs-and-geo.md` (docs sites and AI visibility), `drive.md` (what the Google Drive shows), `request-patterns.md` (how DevRel work was asked for and reviewed) |
| `webinars/` | Notes, runbooks and scripts from past Builders sessions (1, 3, 4, 7) and the intro session deck. The session code is in https://github.com/moi-foundation/MOI-Webinars | `webinars/README.md` |
| `standards/x402-review-package/` | Drafts of three proposed upstream contributions that add MOI to the x402 payments standard and the CASA namespaces, plus an audit, escrow research, follow-ups and a blog draft. Nothing is filed yet | `standards/x402-review-package/README.md` |
| `legacy-skills/` | Older Claude skills (moi-blog, moi-deck, moi-design) replaced by the ones in `skills/moi/`. Kept for reference and because the brand guidelines PDF and the logo pack live only here | `legacy-skills/README.md` |
