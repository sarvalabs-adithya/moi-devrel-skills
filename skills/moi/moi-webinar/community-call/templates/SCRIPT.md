How to read this file

- Each block below is the exact text for one slide. The deck's NOTES array holds the same words, so the presenter window shows what is written here. Edit this file, then run: python3 "$SKILLS/moi-webinar/deck/scripts/sync-notes.py" community-call-<N>/deck/index.html community-call-<N>/SCRIPT.md --confirm (a dry run until --confirm is added)
- A line in square brackets is a cue. Do not read it out. A cue that starts "If the host asks" is read only if the host asks.
- PRESS NEXT means advance the deck, then start the block under it.
- Voice rules: "$SKILLS/moi-webinar/deck/references/spoken-script.md". Call rules: "$SKILLS/moi-webinar/community-call/references/call-script.md".
- Check with: python3 "$SKILLS/moi-webinar/deck/scripts/check-deck.py" community-call-<N>/deck/index.html --script community-call-<N>/SCRIPT.md
