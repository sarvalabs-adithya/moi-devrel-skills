## docs.moi.technology (`sarvalabs/moidocs`)
- Stack: Docusaurus 2.1.0, React 17, Tailwind 3. `engines` in `package.json` says Node `>=16.14` with no upper bound. Which Node version Cloudflare Pages uses is not in the repo, and the owner of the Pages projects is not on record. ASK: Rahul.
- Build: on `main`, `npm run build` is `docusaurus build`. On the PR branch it is `node scripts/generate-llms.mjs && docusaurus build && node scripts/inject-schema.mjs`. Local preview: `npm run start`.
- Routes: pages live under `/docs/`, for example `/docs/learn/fundamentals/account`. `llms.config.json` sets `routeBase` `/docs` and `trailingSlash` false; `docusaurus.config.js` does not set `trailingSlash`.
- Publish: no workflow in the repo (`.github` is absent on `main`). Cloudflare Pages builds `main` to production and every branch to a preview. The README says `develop` deploys to `moichain-docs.pages.dev`, but `develop` ends in July 2023 and is an ancestor of `main`, so that table is stale (checked 2026-10-03).
- Preview: Pages comments on the PR with `<hash>.moichain-docs.pages.dev` and `<branch>.moichain-docs.pages.dev` (seen on #124, 2026-10-02).
- Review: Rahul sets scope and requested changes on #124 on 2026-09-17; Gokul was requested and had not reviewed by 2026-10-02. Recent merged PRs: #113 (Gokul, MOI Wallet section), #119 and #123 and #126 (Abhinav Agarwalla), #120 (squash commit by Robert Špendl, 2026-09-02). Open: #124, #116 (the `context_hash` rename, open since July).
- Merge order: merge #124 before the website PR #57, because the website links to a file that #124 creates (`DEPENDENCIES.md` section 13, local to the previous operator's machine; ASK: Adithya for a copy).

## cocolang.dev (`sarvalabs/coco-docs`)
- Stack: Docusaurus 3.9, React 19, Tailwind 4, `engines` Node `>=18.0`. Routes depend on the state: on PR #12's branch `routeBasePath` is `/`, so the Book is at `/book/...` (the form the style guide uses); on `main` the config sets none, so the Book is at `/docs/book/...` and the internal links are written that way. A `/book/...` link on `main` has no route (`onBrokenLinks` is `throw`; inferred, not built).
- Maintainer: Robert Špendl, who pushes release commits to `main` himself (v0.9.2 on 2026-09-28) and approved #12 on 2026-09-29. Rahul Lenkala also authored Book pages.
- Build: the README says `npm run build -- --no-minify` because of a Tailwind minification problem; Cloudflare runs plain `npm run build`. The README has two typos: `npm runs start` and `cd cocodocs` after cloning `coco-docs`. The dev server is on http://localhost:3000.
- Downloads and the skill zip are on `cdn.moi.technology/cocolang/` (Cloudflare R2). A release adds a section to `docs/releases/index.md` and edits `src/components/DownloadButton/downloads.mjs` (`drift.md`).
- Publish: Pages project `cocodocs`, on merge to `main`. Preview: the Pages check was green on #12; the address form was not recorded (by analogy `<branch>.cocodocs.pages.dev`, inferred).
- Redirects: `static/_redirects` exists on the PR branch only. moidocs and voyage-docs have none.

## js-moi-sdk.docs.moi.technology (`sarvalabs/js-moi-sdk`, folder `docs/`)
- Stack: Sphinx. API blocks are generated from the source comments of the packages (`sphinx_js` and `jsdoc`), so `conf.py` reads `packages/*/lib.cjs`. That implies the packages must be built (`npm run build` at the repo root) before `make html` (inferred from `conf.py`). No Python requirements file is committed in `docs/`: install `sphinx`, `sphinx_js`, `sphinx_rtd_theme`, `jsdoc` and check what is current. ASK: Gokul for the versions that work.
- Build: `npm run docs` at the repo root runs `make -C docs html`. No GitHub workflow builds the docs: `test.yml` runs the tests and `publish.yml` publishes npm packages and the skill zip to R2 (read on `main`).
- Publish and preview: unknown. PR #150 has no preview and was never seen on its real host. ASK: Gokul.
- Review: `CODEOWNERS` lists `@sarvalabs-gokul` and `@sarvalabs-manish` for every file. The previous operator opened #150 from his fork, so a PR from a fork is the route he used; ASK: Rahul whether you push to a fork or to the org.
- Version: `docs/source/conf.py` carries `version` and `release` (`v0.9.0-rc3` on 2026-10-03). It moves at each SDK release.
