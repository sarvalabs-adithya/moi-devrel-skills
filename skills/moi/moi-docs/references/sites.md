## docs.moi.technology (`sarvalabs/moidocs`)
- Stack: Docusaurus 2.1.0, React 17, Tailwind 3. `engines` in `package.json` says Node `>=16.14` with no upper bound. Which Node version Cloudflare Pages uses is not in the repo, and the owner of the Pages projects is not on record. ASK: Rahul.
- Build: on `main`, `npm run build` is `docusaurus build`. On the PR branch it is `node scripts/generate-llms.mjs && docusaurus build && node scripts/inject-schema.mjs`. Local preview: `npm run start`.
- Routes: pages live under `/docs/`, for example `/docs/learn/fundamentals/account`. `llms.config.json` sets `routeBase` `/docs` and `trailingSlash` false; `docusaurus.config.js` does not set `trailingSlash`.
- Publish: no workflow in the repo (`.github` is absent on `main`). Cloudflare Pages builds `main` to production and every branch to a preview. The README says `develop` deploys to `moichain-docs.pages.dev`, but `develop` ends in July 2023 and is an ancestor of `main`, so that table is stale (checked 2026-10-03).
- Preview: Pages comments on the PR with `<hash>.moichain-docs.pages.dev` and `<branch>.moichain-docs.pages.dev` (seen on #124, 2026-10-02).
- Review: Rahul sets scope and requested changes on #124 on 2026-09-17; Gokul was requested and had not reviewed by 2026-10-02. Recent merged PRs: #113 (Gokul, MOI Wallet section), #119 and #123 and #126 (Abhinav Agarwalla), #120 (squash commit by Robert Špendl, 2026-09-02). Open on 2026-10-14: #127 (the skills index to Coco 0.9.3, waiting for Rahul's approval) and #116 (the `context_hash` rename, open since July). #124 merged on 2026-10-13.
- Merge order: moot now. The website PR #57 merged on 2026-10-05 and #124 on 2026-10-13, and the website links to a file that #124 creates, so that link could not resolve in between (inferred; the merge order is not recorded in the handover docs).

## cocolang.dev (`sarvalabs/coco-docs`)
- Stack: Docusaurus 3.9, React 19, Tailwind 4, `engines` Node `>=18.0`. Routes: since #12 merged (2026-10-05) `routeBasePath` is `/`, so the Book is at `/book/...` (the form the style guide uses). ## js-moi-sdk.docs.moi.technology (`sarvalabs/js-moi-sdk`, folder `docs/`)
- Stack: Sphinx. API blocks are generated from the source comments of the packages (`sphinx_js` and `jsdoc`), so `conf.py` reads `packages/*/lib.cjs`. That implies the packages must be built (`npm run build` at the repo root) before `make html` (inferred from `conf.py`). No Python requirements file is committed in `docs/`: install `sphinx`, `sphinx_js`, `sphinx_rtd_theme`, `jsdoc` and check what is current. ASK: Gokul for the versions that work.
- Build: `npm run docs` at the repo root runs `make -C docs html`. No GitHub workflow builds the docs: `test.yml` runs the tests and `publish.yml` publishes npm packages and the skill zip to R2 (read on `main`).
- Publish and preview: unknown. PR #150 had no preview; after it merged on 2026-10-14 its layer was seen live on the real host (`/llms.txt`). ASK: Gokul for the pipeline.
- Review: `CODEOWNERS` lists `@sarvalabs-gokul` and `@sarvalabs-manish` for every file. The previous DevRel (fork `sarvalabs-adithya`) opened #150 from his fork, so a PR from a fork is the route he used; ASK: Rahul whether you push to a fork or to the org.
- Version: `docs/source/conf.py` carries `version` and `release` (`v0.9.0-rc3` on 2026-10-03). It moves at each SDK release. The npm `latest` tag of `js-moi-sdk` is 0.9.0-rc2; rc3 exists on GitHub only (2026-10-13).
