# Baseline against the live docs site and the PR #124 preview, 2026-10-03

Two real runs of `geo-check.sh`, kept as they printed. The first is the live site, which then still showed the state before the sweep (#124 merged on 2026-10-13, so the live site has changed). The second is the Cloudflare Pages preview of open pull request #124 of `sarvalabs/moidocs`, which carries the layer. Read them side by side: every FAIL in the first run is something the pull request fixes, and the WARNs in the second are the follow-ups.
