# Traps: where teaching goes wrong without an error

Facts are as of 2026-10-03. Each row is an incident, stated as a rule, with what to do. Dates are the day of the correction unless marked. The summary table in `../GUIDE.md` holds the nine that bite most often. "The operator" and `ASK:` are defined in `moi-devrel/SKILL.md`. Back to `../GUIDE.md`.

## A. The content is wrong
| # | Rule | Incident | Do |
|---|---|---|---|
| 1 | A fluent explanation can be wrong. Check each sentence against a named source before you say it | 2026-08-26: the previous operator told the assistant it had been wrong about two things on x402 and ordered research first, with nothing pushed. 2026-09-11: drafts said an account pays in KMOI for "everything", said MASN rights were "refused for everyone else" beside "managers cannot modify", and said "a native asset standard made for KMOI alone" | Label each sentence doc-derived, source-derived, receipt-proven or "I will check" (`method.md` section 1). For text that will go public, run `moi-devrel/claim-check` |
| 2 | Test every universal for one counterexample: only, every, nobody, always, never, free, any | 2026-08-07: "only the owner can move funds" was false. 2026-09-11: "Every action on MOI costs fuel" was removed as untrue | Add the limit, or cut the sentence | <!-- slop-lint:ignore -->
| 3 | The release note, the source tip and devnet are three different things | 2026-09-10: devnet answered `payer` and 0.12.0 while the tip had `fee_payer`; the v0.13.0 upgrade was announced for 00:00 UTC on 2026-09-11, and the moment itself is not confirmed (`moi-devrel/claim-check/references/live-reads.md`) | Read the node before "live" (`moi-devrel/claim-check/references/live-reads.md`). A feature found only in a note or the tip is "planned" |
| 4 | A correction must reach every copy, your own explainer included | The false custodian claim was proved false on 2026-08-07 and was still in the session 7 README (lines 85 and 154), EXPLAINER (46), DEMO-PLAN (63 and 248), TRANSCRIPT (23), FACILITATOR-NOTE (57) and the notes of slide 3, read 2026-10-02 | After a correction run `grep -rnF "<old phrase>" .` from the working copy root and fix every hit. | 5 | Counts drift. Recount after every edit and say what a count counts | Namespaces went 55, 50, 49 (2026-09-09). RPC methods 36, then 42. A "27 errors" headline met a table of 26 and a list of 25 (2026-08-21). "Three breaking changes", "four changes" and "five things" in one post | Date the number. Label the unit |
| 6 | A pivot leaves stale explainers behind | The session 7 FACILITATOR-NOTE describes a facilitator package that was removed. STORYLINE says mock mode. Session 8 files describe context inheritance where the blog describes an allowance | Keep one canonical text, date it, mark the rest superseded |
| 7 | A docs page is not always current | Interaction op-code numbers were swapped against source in August 2026; the Networks page is a stub and inherited accounts are "coming soon" (read 2026-10-03) | Cite the docs publicly, check them privately against source (`moi-devrel/claim-check/references/sources-of-truth.md`) |
| 8 | Open every citation you give | 2026-09-10: two spec citations produced by agents did not exist | Open each one and read the sentence it supports before you repeat it |
| 9 | A term the glossary lists as undefined is not yours to define | 2026-09-09: a kill switch docs page was deleted because it did not say what the feature is. ## B. The delivery fails
| # | Rule | Incident | Do |
|---|---|---|---|
| 10 | Answer the question asked, briefly. A wall of text gets asked again | 2026-08-21: paragraph answers and a menu of options were rejected for brief answers and the actual decision. The log shows "sorry I've asked so many times" and "you're going to have to explain that again" after long answers (the cause is read from context, not stated) | First line is the answer. One section per turn. Recommend one decision and state its consequence |
| 11 | Check a restatement against the source, not against yourself | A draft checked against itself passes its own errors (inferred). The standing instruction was to verify against MOI's real protocol code and docs | Open the page. Quote the sentence that settles it |
| 12 | No generic analogy from another company, and no metaphor in public text | 2026-08-27: "don't talk about Stripe". 2026-09-09: "no metaphors". The March 2026 Forge deck leans on "the contract is the bank" and was written before the stricter rule (inferred) | Teach in MOI context. Keep any plain picture to the chat and tell the operator which sentences are only for the chat |
| 13 | After a no, teach inside the flow the operator chose | 2026-08-31: the assistant kept proposing (inferred from the replies) to create or fund an account for an agent after being told to use the MOI Wallet extension and the operator's own funded account | Use the chosen flow. Do not propose the rejected one again |
| 14 | An example says what is real and what is constructed | Demos run on real devnet interactions with no mock mode. About 2026-08-05, two days before the 2026-08-07 session, the registry write path was down, so session 7's deck and transcript were rewritten to use existing agents and show only the happy path, with no code changed | Write "(constructed)" or "simulated" next to anything you did not run. Prefer a read of a hash that exists on the current devnet |
| 15 | Do not reuse an old demo's numbers or claims after a reset | Devnet was wiped on 2026-08-15 and again in the reset announced for 2026-09-11 (`moi-devrel/references/devnet.md`, reset history). No run of any session is on record since (`moi-webinar/SKILL.md`, read 2026-10-02) | Run the demo's preflight first. Treat old fuel and hash figures as history |
| 16 | A status says only what was done | 2026-09-10: a status message claimed an action that was not taken and was removed | "Taught" in the hand-back means the operator restated it and was marked right. Otherwise write it as a to-do |
| 17 | Write dates in full and avoid "since" | The September post says live "since 11 September" while the oldest listed interaction is dated 2026-09-10 13:18 UTC. A 12-hour release time was misread once (`moi-devrel/references/terminology.md`, table C) | Use an explicit date and 24-hour UTC. A read proves now, never since <!-- slop-lint:ignore --> |

## C. Safety and scope
| # | Rule | Incident | Do |
|---|---|---|---|
| 18 | Never read, confirm or repeat a recovery phrase, in chat or on a recorded call | Devnet recovery phrases were pasted in chat on several days between 2026-06 and 2026-09. 2026-09-24: a phrase read on a screen share reached the meeting notes | Wallet steps are the operator's. If one appears, do not repeat it, say it is exposed (`moi-devrel/references/consent-and-identity.md`, section 5) |
| 19 | An explainer can name private source and people. Keep it out of any public repo | Private source informs checks and is never cited (standards rule of 2026-09, `moi-devrel/claim-check/references/sources-of-truth.md`, "Private source"). A tracked file in a public repo carried a reviewer's name, and the session 8 internal files were gitignored only on the branch | Use the self-ignoring `explain-<slug>/` folder from step 10. Name no private path and no reviewer in anything that could be shared |
| 20 | Keep protocol and application apart | 2026-09-17: Rahul asked that Launchpad docs leave the protocol docs, because "Launchpad is just an app which uses MOI" | Teach the registry as protocol. Teach the Launchpad, Explorer and MCP as applications, with `moi-launchpad-ops` and its siblings |
| 21 | Do not spend funds to explain | A demo run, an asset creation and a deploy all spend devnet funds | Ask first, naming the paying account and the cost. Offer a read of an existing hash instead |
| 22 | Do not insist, do not fan out | 2026-08-04: a multi-agent verification started unasked and burned the operator's credits | Do the checking inline. Sub-agents only on request, with the count stated first |
