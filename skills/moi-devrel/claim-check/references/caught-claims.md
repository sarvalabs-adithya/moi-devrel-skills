## Patterns
1. Release notes and docs can be wrong. Check the tag. 2. A universal needs a counterexample search. 3. A scope word is lost between sections. 4. A correction reaches one file and not the other copies. 5. Counts drift. 6. A status file says the code does something it does not. 7. An agent or a draft invents a name or a citation. 8. A time written for the writer is wrong for the reader.
