# MOI mini deck: speaking script

An example script for the six-slide example deck. Read it aloud at a calm pace, about two minutes in all.

How to read this file

- Each block is the exact text for one slide. The deck's NOTES array holds the same text, word for word.
- A line in square brackets is a cue for you. Do not read it out.
- PRESS NEXT means advance the deck, then start the block below it.

---

==============================================================
## OPENING SLIDE 1 · Title
==============================================================

Welcome to the example deck. It has six slides, and each one shows a single component, so you can see how the pieces look and how a script reads when it is spoken aloud.

---

==============================================================
## PRESS NEXT --> SLIDE 2 · Cards
==============================================================

This slide shows cards. A card carries a short label, a headline and then either a sentence or a short list, and three of them fit comfortably in a row. When a slide needs more than three, it is usually two slides, so split it before shrinking any type.

---

==============================================================
## PRESS NEXT --> SLIDE 3 · Steps and code
==============================================================

This slide shows steps and a code block, which are built for dark backgrounds. Each step puts a command or a file name on the left and the point the audience should take from it on the right.

[SWITCH TO THE TERMINAL AND RUN THE COMMAND ON THE FIRST STEP]

When you are back on the slides, the code block underneath is read from top to bottom, comment first, so say what each line does in the order the audience sees it.

---

==============================================================
## PRESS NEXT --> SLIDE 4 · Stats
==============================================================

This slide shows the stats row. The three numbers here are placeholders and carry no meaning. On a real slide every number is supplied by a named person, and the label under it says what it counts, so the audience knows what they are reading.

---

==============================================================
## PRESS NEXT --> SLIDE 5 · Comparison table
==============================================================

This slide shows the comparison table. Each row has a name, a detail and a value, and the highlighted row is the one that matters most, so use it once. The small line inside a cell holds the extra detail you would otherwise say out loud.
